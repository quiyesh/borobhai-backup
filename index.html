About the Application

Borobhai Secure Backup is a private, personal-use backup application designed to protect the configuration and data of a personal AI assistant.

Google Drive Integration

The application uses the Google Drive API to store and retrieve encrypted backup files in the authorized user's Google Drive account.

Access is limited to files created or authorized for use by the application.

Security and Privacy

Backup files are encrypted before being transferred to Google Drive. The application is intended for personal use and does not sell user data or use it for advertising.
