Privacy Policy

Borobhai Secure Backup

Effective date: November 26, 2026

1. About the Application

Borobhai Secure Backup is a private, personal-use application designed to back up and recover personal AI infrastructure and configuration data. It is not offered as a public backup service.

2. Google User Data Access

The application uses Google OAuth and the Google Drive API with the drive.file permission. Access is limited to files created by or explicitly authorized for the application.

Google Drive file contents and associated file metadata are accessed only as needed to upload, retrieve, verify and manage backup files.

3. Data Usage

Google user data is used exclusively for backup, integrity verification, storage management and disaster recovery. It is not used for advertising, profiling, or training AI models.

4. Data Storage and Security

Backup files are encrypted locally using rclone crypt before being transferred to Google Drive.

Local backup and recovery files may be stored on the authorized hosting server. Access to credentials and encryption keys is restricted to the application owner.

5. Data Sharing

The application does not sell Google user data or share it with advertisers. Data is processed using the hosting infrastructure and Google Drive solely to provide backup and recovery functions.

6. Data Retention and Deletion

Backup files are retained according to the application owner's backup settings. The owner can delete cloud backup files directly from Google Drive and remove local copies from the hosting server.

7. Revoking Access

Google authorization can be revoked at any time through the Google Account third-party connections settings.

Manage Google Account Connections

8. Google API Compliance

Borobhai Secure Backup's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Google API Services User Data Policy

9. Contact

For privacy-related questions, contact the application owner through the support email provided on the Google OAuth consent screen.
